Bagaimana demo ini bekerja?

Tiga komponen yang saling terhubung secara real-time.

1

Widget di website

Pesan dari bubble chat dikirim melalui Socket.IO. Saat offline, pesan masuk antrean dan dikirim otomatis.

2

Dashboard agent

Agent menerima tiket, membalas, mengirim catatan internal, dan memantau SLA dari browser.

3

Aplikasi mobile

Balasan yang sama tampil di aplikasi Flutter, lengkap dengan antrean offline dan notifikasi.

Pasang di website Anda

Satu baris script, tanpa framework.

<script src="http://localhost:3000/widget/chat-widget.js"
        data-api="http://localhost:3000" async></script>

Ganti host dengan domain server helpdesk Anda. Widget memakai Shadow DOM sehingga tidak bentrok dengan CSS website.
